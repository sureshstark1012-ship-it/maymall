# MayMall

A lightweight website starter using HTML, CSS, and Vite. Features will be added step by step.

## Development

Requires Node.js 22.12 or newer.

```sh
npm ci --cache /tmp/maymall-npm-cache
npm run dev -- --host 0.0.0.0
```

## Production build

```sh
npm run build
```

The generated website is in `dist/`. Run `npm run preview -- --host 0.0.0.0` to inspect it locally.
